# The welcome tour.

Welcome to r7z
欢迎使用 r7z

A fast archiver that opens what 7-Zip opens and extracts several times faster. Here's a quick look at what it can do. It takes a minute, and you can skip it anytime.
一款快速的压缩软件，能打开 7-Zip 可打开的格式，解压速度快数倍。下面快速了解它的功能，只需一分钟，也可以随时跳过。

Look inside without extracting
无需解压即可查看

Select a file to preview pictures, text and code straight from the archive. Paste the hash a website publishes for a download, and r7z tells you whether the file matches.
选择文件即可直接在压缩包中预览图片、文本和代码。粘贴网站公布的下载哈希值，r7z 会告诉您文件是否匹配。

See what takes up space
查看空间占用

The space map shows an archive by size, down to single files, colored by type. Point at a block for details, and double-click a folder to go in.
空间图按大小显示压缩包的内容，精确到单个文件，并按类型着色。将鼠标指向色块可查看详细信息，双击文件夹可进入。

Know what you're opening
了解您打开的内容

Every archive is checked as it opens. Files that would land outside the folder, programs dressed up as documents and zip bombs are flagged before you extract anything.
每个压缩包在打开时都会接受检查。会解压到文件夹之外的文件、伪装成文档的程序和压缩炸弹，都会在解压之前标记出来。

Extract, and change your mind
解压后也能反悔

Extract here makes a folder only when the archive needs one, so files never spill everywhere. Every extraction can be undone, and anything it replaced comes back.
“解压到此处”仅在需要时创建文件夹，文件不会散落一地。每次解压都可以撤销，被替换的内容也会恢复。

Find anything
快速查找

Press Ctrl+Shift+F to reach files, folders, places and actions from one box. Ctrl+F filters the folder you're in.
按 Ctrl+Shift+F，在一个搜索框中查找文件、文件夹、位置和操作。按 Ctrl+F 可筛选当前文件夹。

Right from Explorer
直接在资源管理器中使用

Right-click an archive to extract, test it or convert it to 7z. Right-click any files or folders to compress them to .7z or .zip in one click. No need to open r7z first.
右键单击压缩包，即可解压、测试或转换为 7z。右键单击任意文件或文件夹，一键压缩为 .7z 或 .zip。无需先打开 r7z。

Right-click an archive to extract, test it or convert it to 7z. Right-click any files or folders to compress them to .7z or .zip in one click. Install r7z to add these menus, and to find r7z in the Start menu and Windows search. It keeps itself up to date with signed updates.
右键单击压缩包，即可解压、测试或转换为 7z。右键单击任意文件或文件夹，一键压缩为 .7z 或 .zip。安装 r7z 后即可添加这些菜单，并可在开始菜单和 Windows 搜索中找到它。r7z 会通过已签名的更新保持最新版本。
