## Download

**[r7z-0.1.0-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.0/r7z-0.1.0-windows-x64.zip)** contains both programs. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app. Double-click to start, or drop an archive on it. |
| `r7z.exe` | The command line tool. Same commands and switches as 7-Zip's `7z.exe`. |

Windows 10 or 11, 64-bit.

## What's in it

**Speed**
- Extracts 2 to 6 times faster than 7-Zip on archives full of small files
- Creates 7z 1.3 to 1.8 times faster at the default level, and `.tar.gz` in one step about 8 times faster than 7-Zip's two-step pipe

**Desktop app**
- Browse folders and archives in one window, with archives inside archives opening in place
- Preview images, text and hex without extracting; paste a published hash to check a download
- Space map that shows what takes room, down to single files
- Safety check on open that flags path tricks, disguised executables and zip bombs
- Smart extract, batch extract, convert between formats, and undo for the last five extractions
- Drag files out to Explorer, or copy and paste them
- Open an archive as a folder in Explorer, without extracting it (needs the Windows Projected File System feature)
- Light and dark themes, Explorer right-click menu, Ctrl+Shift+F to search everywhere

**Formats**
- Read and write: 7z, zip, tar, gzip, bzip2, xz
- Read: zstd, lz4, Z, lzma, cab, cpio, ar and deb, rpm, arj, lzh, xar and pkg, wim and esd, split `.001` volumes, Base64, Intel HEX
- Correct file names for zips made on Japanese, Chinese, Korean and Russian systems
- `x -recover` rescues what is readable from damaged and truncated archives

## Updates

From this version on, the desktop app checks for new releases once a day and offers them
with one click. Updates are signed with an Ed25519 key, and the signature is checked
against a key built into the app before anything is installed. You can turn the check off,
or have updates installed without asking, in Settings → Updates.

## Verify your download

This release was built by GitHub Actions from the `v0.1.0` tag. To confirm a file came from
that build:

```
gh attestation verify r7z-0.1.0-windows-x64.zip --repo hdunl/r7z
```

`SHA256SUMS` lists the hash of every file. The programs are not code-signed yet, so Windows
SmartScreen may ask for confirmation the first time; choose **More info → Run anyway**.

## Not in this release

RAR, disk images (ISO, VHD, DMG) and installers, and updating files inside an existing
archive. See the [roadmap](https://github.com/hdunl/r7z#roadmap).
