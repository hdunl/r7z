## Download

**[r7z-0.1.2-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.2/r7z-0.1.2-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `package\` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Welcome tour.** The first time you open r7z, a short tour shows what it can do, with
  screenshots: previews and hash checks, the space map, the safety check, extract with
  undo, search everywhere and the Explorer menu. Skip it with one click or Esc, and open
  it again anytime from Settings → Welcome tour or search everywhere.

## Verify your download

```
gh attestation verify r7z-0.1.2-windows-x64.zip --repo hdunl/r7z
```

Or offline, with the bundle from this page:

```
gh attestation verify r7z-0.1.2-windows-x64.zip --bundle r7z-0.1.2.sigstore.json --repo hdunl/r7z
```

The programs are not code-signed yet, so Windows SmartScreen may ask for confirmation the
first time; choose **More info → Run anyway**.
