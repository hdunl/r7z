## Download

**[r7z-0.1.3-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.3/r7z-0.1.3-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Signed and verified.** The programs, the shell extension and the Windows 11 menu
  package are signed with a Public Trust certificate through Microsoft's Artifact
  Signing, and timestamped. Windows shows a verified publisher instead of an "unknown
  publisher" warning.
- **The Windows 11 menu works everywhere.** Because the menu package is now signed,
  Settings → Explorer menu → Add to menu puts an **r7z** submenu in Windows 11's main
  right-click menu on any PC, without Developer Mode.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.3-windows-x64.zip --repo hdunl/r7z
```
