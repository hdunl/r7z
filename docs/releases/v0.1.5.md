**[r7z-0.1.5-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.5/r7z-0.1.5-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

Windows 10 or 11, 64-bit.

## What's new

The **r7z** submenu in Windows 11's right-click menu now offers what 7-Zip's does:

| Right-click | You get |
|---|---|
| An archive | Open with r7z · Extract here · Extract to "name\" · **Test archive** · **Convert to .7z** · **Add to "name.7z"** · **Add to "name.zip"** · Add to archive… |
| A folder | **Open in r7z** · **Add to "name.7z"** · **Add to "name.zip"** · Add to archive… |
| Any other files | **Add to "name.7z"** · **Add to "name.zip"** · Add to archive… |

- **Add to "name.7z" / "name.zip"** compress in one click with the default settings. If
  an archive with that name exists, the new one gets a number instead of replacing it.
- **Test archive** checks every file without extracting anything.
- **Convert to .7z** repacks a zip (or any other archive r7z opens) into a smaller 7z.
  The original stays as it is.

If the new entries don't show after the update, restart Explorer or sign out and back in:
Windows keeps the old menu handler loaded until then.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.5-windows-x64.zip --repo hdunl/r7z
```
