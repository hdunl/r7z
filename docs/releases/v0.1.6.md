## Download

**[r7z-0.1.6-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.6/r7z-0.1.6-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Nothing else to install.** Earlier builds needed the Microsoft Visual C++
  Redistributable, which most PCs have but a fresh Windows install doesn't. The C runtime
  is now built into the programs, so r7z starts everywhere.

New in 0.1.5: more entries in the right-click menu (Add to "name.7z" and "name.zip", Test
archive, Convert to .7z, Open in r7z). See the
[0.1.5 release](https://github.com/hdunl/r7z/releases/tag/v0.1.5).

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.6-windows-x64.zip --repo hdunl/r7z
```
