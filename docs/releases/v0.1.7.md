## Download

**[r7z-0.1.7-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.7/r7z-0.1.7-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Install r7z.** Click **Install r7z** on the welcome tour's last page or in Settings. r7z
  copies itself to `%LOCALAPPDATA%\Programs\r7z` and shows up where Windows apps do:
  - the Start menu and Windows search
  - Settings → Installed apps, with a working Uninstall button
  - Run → `r7z`
  - "Open with" and Default apps for archive types
  - the right-click menu, including Windows 11's main menu

  It needs no administrator rights, and r7z never takes over a file type by itself. If
  you already use r7z, the app offers to install once.
- **Uninstall cleanly.** Uninstalling from Settings → Apps removes everything r7z added
  and its install folder, and keeps your settings.
- For scripts: `r7z-gui --install` and `r7z-gui --uninstall --quiet`.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.7-windows-x64.zip --repo hdunl/r7z
```
