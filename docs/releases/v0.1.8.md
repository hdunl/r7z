## Download

**[r7z-0.1.8-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.1.8/r7z-0.1.8-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

| File | 0.1.7 | 0.1.8 |
|---|---:|---:|
| `r7z-gui.exe` | 12.7 MB | 10.1 MB |
| `r7z_shell.dll` | 2.3 MB | 0.3 MB |
| `r7z.exe` | 3.5 MB | 3.5 MB |

- The interface code is built for size. The code that compresses and extracts is not,
  so r7z is exactly as fast as before.
- The app uses Windows' own fonts instead of carrying copies of its own.
- The Explorer menu extension only needs to recognize archive names, and no longer
  carries every archive parser along.

New in 0.1.7: **Install r7z** puts it in the Start menu, Windows search and Installed
apps. See the [0.1.7 release](https://github.com/hdunl/r7z/releases/tag/v0.1.7).

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.8-windows-x64.zip --repo hdunl/r7z
```
