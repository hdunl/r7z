## What's new

Measured against 0.1.8 on a source tree (87 MB, 6,554 files):

| | 0.1.8 | 0.1.9 |
|---|---:|---:|
| Extract a 7z made by 7-Zip | 1.13-1.38 s | **0.88-1.15 s** |
| Create a zip | 0.78-1.11 s | **0.49-0.61 s** |
| Test a `.tar.gz` | 0.32 s | **0.23-0.26 s** |

- **Extraction keeps the disk busy.** Decoding no longer waits for each file to be
  created. Folders are created and stamped in parallel, and big solid blocks get most of
  the decoding threads.
- **zip and gzip use a faster Deflate engine** (zlib-rs). Archives come out the same size
  as before.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.1.9-windows-x64.zip --repo hdunl/r7z
```
