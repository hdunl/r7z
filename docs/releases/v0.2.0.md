## Download

**[r7z-0.2.0-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.2.0/r7z-0.2.0-windows-x64.zip)** contains everything. Unzip it anywhere, no installer needed.

|---|---|

Windows 10 or 11, 64-bit.

## What's new

- **RAR archives.** RAR 4 and RAR 5, including solid, multi-part and password-protected
  archives. Every test archive extracts byte for byte like 7-Zip.
- **Disk images.** ISO, UDF, DMG, VHD, VHDX, VMDK and QCOW2, with the partitions and the
  FAT, exFAT, NTFS, ext2/3/4 and HFS+ file systems inside. Images are read in place, so a
  large disk opens without loading it into memory.
- **Installers.** MSI, NSIS, self-extracting 7z, zip, RAR and cab files, CHM help files,
  and the icons and resources inside programs ("Open as archive"). An ordinary program is
  never treated as an archive.
- **Change archives in place.** Add, replace, delete and rename files in 7z, zip and tar
  archives with `a`, `u`, `d` and `rn`. Untouched data is copied as is, and the original
  stays intact if anything fails.
- **More ways to compress.** Write zstd, lz4 and `.Z`, also as `.tar.zst`, `.tar.lz4`
  and `.tar.Z`. Programs compress smaller with BCJ2 and filters for ARM, ARM64 and other
  processors, picked from each file's header.
- **Faster maximum compression.** `-mx7` to `-mx9` find matches on their own thread:
  `-mx9` took 25 s instead of 32 s on a large source tree. It is still slower than 7-Zip
  at this level.
- **Older and damaged archives.** Reads split zips (`.z01`) and the legacy zip methods
  Implode, Shrink and Reduce, and recovers the intact blocks of a damaged bzip2 or xz file.
- **See what's new before updating.** From this version on, r7z shows a release's notes
  before it installs the update.

The programs are larger with all this: r7z.exe is 4.8 MiB and the desktop app 10.9 MiB.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.2.0-windows-x64.zip --repo hdunl/r7z
```
