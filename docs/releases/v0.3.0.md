## Download

**[r7z-0.3.0-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.3.0/r7z-0.3.0-windows-x64.zip)** contains:

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Security fixes. Please update.** A crafted archive could create a symbolic link that
  pointed outside the extraction folder, so a later extraction could write through it.
  Files opened from inside a downloaded archive skipped SmartScreen and Protected View;
  they now keep the archive's Mark of the Web. A few bytes in a disk image or RAR 5 header
  could ask for huge amounts of memory; those sizes are now limited. Updates install from
  the bytes that were verified, not from a temporary copy another program could swap.
- **Simplified Chinese.** The desktop app and the right-click menus are available in
  Chinese. r7z follows your Windows language, and Settings → Language chooses one for the
  app. The command line stays in English.
- **Inno Setup installers.** Versions 5.5 to 6.7 open like any archive, with each file's
  checksum verified.
- **Older RAR archives.** RAR 1.5 and 2.0 archives now open, including solid and
  multi-volume ones.
- **A leaner Microsoft Store version.** It no longer contains the updater or the
  installer, which the Store handles, so it holds no network code at all, and its programs
  are now code-signed like the ones in the zip. This follows a report of Huorong flagging
  the Store build ([#50](https://github.com/hdunl/r7z/issues/50)).
- **Smaller fixes.** Entries with the same name in one archive now extract predictably.
  Stopping r7z with Ctrl-C no longer leaves a temporary file behind. Executables in zstd
  zips come out 2.7% smaller. File names that aren't valid Unicode no longer close the app.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.3.0-windows-x64.zip --repo hdunl/r7z
```
