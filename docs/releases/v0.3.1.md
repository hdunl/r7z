## Download

**[r7z-0.3.1-windows-x64.zip](https://github.com/hdunl/r7z/releases/download/v0.3.1/r7z-0.3.1-windows-x64.zip)** contains:

| File | What it is |
|---|---|
| `r7z-gui.exe` | The desktop app |
| `r7z.exe` | The command line tool, with 7-Zip's commands and switches |
| `r7z_shell.dll`, `r7z-shell.msix` | The Windows 11 context menu |

Windows 10 or 11, 64-bit.

## What's new

- **Security fixes. Please update.** An NSIS installer could be crafted to make r7z use
  memory without limit as soon as it was listed; what its script can ask for is now
  bounded. The portable copy's installer put folder names straight into PowerShell and cmd
  scripts, so a curly apostrophe in a name broke installing and a crafted name could run
  commands. Names no longer pass through script text.
- **Creating over an existing archive is safe.** The old archive used to be deleted before
  the new one was moved into place, and was lost if that last step failed. It is now
  replaced in one step.
- **A lighter right-click menu.** Right-clicking a large `.exe` made the menu read the
  whole file up to ten times. It now takes one short look per selection.
- **Simplified Chinese.** English no longer shows through in the messages after extracting
  and testing, the status bar, progress and undo, and several lines are corrected.
- **Open with.** r7z is offered for `.rar`, `.iso` and `.dmg` files. An installed copy
  picks them up the first time it starts after updating.
- **Smaller fixes.** Installing over an existing copy puts the old files back if copying
  fails. Open as folder no longer hangs on closing or after a damaged block.

## Verify your download

Right-click a program → Properties → Digital Signatures, or in PowerShell:

```
Get-AuthenticodeSignature r7z-gui.exe
```

The build itself can be traced to this repository's release workflow:

```
gh attestation verify r7z-0.3.1-windows-x64.zip --repo hdunl/r7z
```
